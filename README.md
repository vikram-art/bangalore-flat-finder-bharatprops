# Bangalore Flat Finder by BharatProps

East Bangalore projects on one 3D map: filter by home type, BHK, budget, size, stage, amenities, corridor, and distance from a metro, tech park, mall or any dropped pin.

Live site: https://vikram-art.github.io/bangalore-flat-finder-bharatprops/

## Files

- `index.html`: the site
- `projects.csv`, `units.csv`: projects and their unit types
- `places.csv`, `metro_stations.csv`: tech parks, malls, stations and metro stops
- `basemap.json`: built-in roads, water and metro lines
- `gmaps.png`: icon for the Google Maps link
- `maplibre-gl.js`, `maplibre-gl.css`: map library (BSD licence)

To edit the data, see `DATA-GUIDE.md`.
